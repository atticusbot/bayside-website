# Bayside AI Website

This is the public Bayside AI website.

## Brand Voice

Before editing site copy, read:

- `docs/brand/bayside-voice-brief.md`

Core rule: do not sell AI. Sell the disappearance of avoidable work.

## Getting Started

Install dependencies, then run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

The homepage lives at `src/app/page.tsx`. The page auto-updates as you edit the file.

Before pushing changes:

```bash
npm run build
```

## Using Claude On Another Computer

Clone the repo, install dependencies, and open the folder in Claude:

```bash
git clone https://github.com/atticusbot/bayside-website.git
cd bayside-website
npm install
npm run dev
```

## Deploy on Vercel

The repo is connected to Vercel. Pushing to the deployed branch should trigger a deploy automatically.

Check out our [Next.js deployment documentation](https://nextjs.org/docs/app/building-your-application/deploying) for more details.
