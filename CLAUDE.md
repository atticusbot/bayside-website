# Claude Instructions

This is the Bayside AI website repo.

## Brand Voice

Before editing homepage, service, proposal, or case-study copy, read:

- `docs/brand/bayside-voice-brief.md`

The short version:

- Do not sell AI. Sell the disappearance of avoidable work.
- Be plain, calm, specific, and operational.
- Avoid generic AI/services language.
- Use AI only when it clarifies the mechanism. Never use it as decoration.
- Avoid em dashes in finished copy.

## Development

Use the standard Next.js flow:

```bash
npm install
npm run dev
npm run build
```

Run `npm run build` before pushing website changes.
